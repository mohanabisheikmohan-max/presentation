# Quantum Computing — A Field Guide Website

Files:
- index.html — complete website
- style.css — responsive design, cards, grids, animations
- script.js — loader, scroll reveal, parallax

Run locally:
1. Open this folder in VS Code.
2. Install/enable Live Server.
3. Right-click index.html → Open with Live Server.

The website content is based on the supplied Quantum_Computing presentation.
